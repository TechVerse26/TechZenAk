# রিলিজ — সাইনিং, লক-ফাইল, Play Store

## ১. রিলিজের আগে (একবার)
1. **ডিবাগ রানে লক-ফাইল তৈরি:** `build-reports` আর্টিফ্যাক্ট নামান → `vendor.lock.json` → `scripts/web/`, `quran-data.lock.json` → `tools/quran-data/` কমিট। এগুলো ছাড়া রিলিজ ওয়ার্কফ্লো শুরুতেই থামে (ইচ্ছাকৃত)।
2. **কুরআন ডেটার উৎস পর্যালোচনা:** `tools/quran-data/editions.json` (`quran-uthmani`, `quran-simple-clean`, `bn.bengali`, `en.sahih`)। আসল ডেটা প্রথম রানে আসে; সতর্কতা (জুজ-শুরুর অমিল) থাকলে `build-reports/web-bundle.log` দেখুন। **কুরআন/অনুবাদের লাইসেন্স ও উৎস আপনার দায়িত্বে নিশ্চিত করুন** (অনুবাদ ও সংশ্লিষ্ট স্বত্ব) — আমি তা যাচাই করতে পারি না।
3. **Firebase/Google Cloud:** `README.md` §৩ (API key referrer, authorized domains)।
4. **Vercel:** নতুন `api/_cors.js` সহ ডিপ্লয় (অ্যাপ থেকে AI/স্টোরি কল তার ওপর নির্ভর করে)।

## ২. সাইনিং (বিদ্যমান ব্যবস্থা, অপরিবর্তিত)
GitHub Secrets: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`। কীস্টোর **কখনও কমিট নয়** (`.gitignore`-এ `*.key`, `*.pem`)। ডিবাগ কীস্টোর (`android-build/debug.keystore`) ইচ্ছাকৃতভাবে কমিট করা (স্থির ডিবাগ-সাইন, বিদ্যমান ডিজাইন)।
রিলিজ: `Actions → Build Android app → release = true`। ফলাফল signed APK + AAB (বিদ্যমান ধাপ) — **এই সেশনে কোনোটাই বানানো হয়নি**।

## ৩. Google Play চেকলিস্ট
| বিষয় | করণীয় |
|---|---|
| `SCHEDULE_EXACT_ALARM` | Play Console → App content → "Exact alarm" ঘোষণা: নামাজ/আযকারের **ব্যবহারকারী-নির্ধারিত রিমাইন্ডার**; ইউজার সেটিংসে অনুমতি দেয়, না দিলেও রিমাইন্ডার (ইনএক্স্যাক্ট) চলে। `USE_EXACT_ALARM` ব্যবহার **করা হয়নি** (ইচ্ছাকৃত) |
| `POST_NOTIFICATIONS` | বিদ্যমান; রান্টাইম অনুমতি বিদ্যমান ফ্লোতে |
| `RECEIVE_BOOT_COMPLETED` | রিবুটের পর রিমাইন্ডার পুনঃশিডিউল |
| Data safety / গোপনীয়তা | বিদ্যমান `privacy.html` (অ্যাপের বান্ডলে এখন স্থানীয়, অফলাইনে খোলে); নতুন ডেটা: ডিভাইসে নামাজের লোকেশন (উইজেট/অ্যালার্মের জন্য নেটিভ স্টোরে) — গোপনীয়তা নীতিতে উল্লেখ করুন |
| অ্যাকাউন্ট ডিলিট | বিদ্যমান `account-deletion.html` (বান্ডলে) |
| App Links | `SITE_URL` দিলে অটো-ভেরিফাই ফিল্টার; `/.well-known/assetlinks.json` ওয়েবসাইটে প্রকাশ (বিদ্যমান ধাপ) |
| ১৬ KB পেজ-সাইজ / targetSdk | Capacitor 8 টেমপ্লেটের ডিফল্ট (compileSdk 36); আমি বদলাইনি |
| Lint | `lintVitalRelease` রিলিজে চলে: ওভারলে ইচ্ছাকৃতভাবে `NewApi`/`MissingDefaultResource` এড়িয়ে লেখা (লিন্টার `MissingDefaultResource` ধরে); **চালিয়ে যাচাই হয়নি** |

## ৪. পরিচিত সীমাবদ্ধতা (রিলিজ নোটে রাখুন)
- অডিও এখনো স্ট্রিমিং/ব্রাউজার-ক্যাশ; অফলাইন অডিও নয়।
- নির্ভুল রিমাইন্ডার ব্যবহারকারীর "Alarms & reminders" অনুমতির ওপর; কিছু ফোনে ব্যাটারি অপ্টিমাইজেশন অ্যালার্ম আটকাতে পারে।
- অফলাইন নামাজের সময় ৮টি পদ্ধতিতে (অন্য পদ্ধতি অনলাইনে)।
- নামাজের সময় গণনা-ভিত্তিক সহায়ক; স্থানীয় মসজিদের টাইমটেবিল সামান্য ভিন্ন হতে পারে।
- ওয়েব-কপি আপডেটে অ্যাপ আপডেট করতে ওয়ার্কফ্লো চালাতে হয়।
