# কুরআন বাংলা — স্বয়ংসম্পূর্ণ (Standalone) Android অ্যাপ

> পরিবর্তনের সারকথা: Android অ্যাপ আগে ছিল `https://quranbangla.vercel.app`-এর উপর একটা Capacitor মোড়ক (`server.url`)।
> এখন অ্যাপ **নিজের ওয়েব বান্ডল APK-র ভেতরে** বহন করে, কুরআন ডেটা সমেত, এবং লাইভ ওয়েবসাইট বা ইন্টারনেট ছাড়াই খোলে।
> ওয়েবসাইট (Vercel) অপরিবর্তিত — তার `index.html` একটুও বদলানো হয়নি।

প্যাকেজ আইডি অপরিবর্তিত: `com.techverse.quranbangla`।

## ১. আর্কিটেকচার

```
 GitHub Actions
 ├─ scripts/web/build-web.mjs ──► build/www/   (অ্যাপের নিজস্ব ওয়েব কপি + bundle-manifest.json, প্রতি ফাইলের SHA-256)
 │    ├─ js/ css/ app/ assets/ icons/ …           (ওয়েব অ্যাপ, ওয়েবসাইটের ফাইলই)
 │    ├─ vendor/…                                  (Firebase SDK, Font Awesome, Google Fonts, EmailJS, QR লাইব্রেরি — CDN-এর কপি)
 │    ├─ data/quran/…                              (কুরআন: আরবি ×২ + বাংলা + ইংরেজি, যাচাই-করা, চেকসাম-বাঁধা)
 │    └─ index.html (কপি)                          (CDN ট্যাগ → স্থানীয় ফাইল; স্ট্যান্ডঅ্যালোন স্তর যোগ)
 ├─ android-build/create-project.sh ──► Capacitor প্রজেক্ট ── www/ = ওপরের বান্ডল (হ্যাশ মিলিয়ে বসানো)
 │                                       └─ android-build/native/ (Kotlin: উইজেট, রিমাইন্ডার, Room, ব্রিজ)
 └─ audit-apk.mjs ──► তৈরি APK খুলে প্রতিটি বান্ডল ফাইল আবার SHA-256-এ মেলানো, server.url নেই কি না দেখা
```

অ্যাপ চালু হওয়ার পর স্তরগুলো (`index.html`-এ এই ক্রমেই লোড হয়):

| স্তর | ফাইল | কাজ |
|---|---|---|

| স্থানীয় কুরআন | `js/local-data.js` | `api.alquran.cloud`-এর হুবহু আকারে উত্তর দেয় বান্ডল-করা ডেটা থেকে (চেকসাম মিলিয়ে) — `reader.js`, `search.js` ইত্যাদি **একটাও লাইন না বদলে** চলে |

## ২. বিল্ড

### CI (GitHub Actions) — সাধারণ পথ
`Actions → Build Android app → Run workflow`। নতুন ধাপগুলো `Build the web bundle` (ব্যর্থ হলে APK-ই হয় না) এবং বিদ্যমান full → safe ফলব্যাক।
- `full`: ওয়েব বান্ডল + Kotlin নেটিভ মডিউল। কম্পাইল ব্যর্থ হলে স্বয়ংক্রিয়ভাবে **`safe`** বিল্ড: একই স্বয়ংসম্পূর্ণ বান্ডল, কিন্তু Kotlin ছাড়া (উইজেট/নেটিভ রিমাইন্ডার থাকে না)।
- ওয়েব ফাইল (`js/`, `css/`, `app/` …) বদলালে অ্যাপে পৌঁছাতে **ওয়ার্কফ্লো আবার চালাতে হবে** (অ্যাপের নিজস্ব কপি আছে)।
- `QR_NATIVE_MODULES=none` দিলে Kotlin ছাড়াই বিল্ড (সমস্যা আলাদা করতে কাজে লাগে)।

### লোকাল
```bash
node scripts/web/build-web.mjs --out build/www          # ইন্টারনেট লাগে: CDN + কুরআন ডেটা (ক্যাশ: --vendor-cache, --quran-cache)
node scripts/web/audit-launch.mjs build/www             # "অফলাইনে চালু হবে কি?" — ফাইল পড়ে প্রমাণ করে
SITE_URL=https://quranbangla.vercel.app QR_PROJECT_DIR=/tmp/app APP_ID=com.techverse.quranbangla APP_NAME="কুরআন বাংলা" \
  APP_VERSION=1.0.0 APP_VERSION_CODE=1 bash android-build/create-project.sh full
npm run build:ts      # src/native/*.ts → js/quran-native.js (tsc, strict)
npm run lint:native   # Kotlin/XML ওভারলের স্ট্যাটিক পরীক্ষা (কম্পাইলার নয়)
npm run test:web      # সব নতুন টেস্ট
```

### লক-ফাইল (প্রথম রানের পর অবশ্যই কমিট করুন)
প্রথম CI রান দুটো ফাইল **লেখে** (ওয়ার্কফ্লো `build-reports` আর্টিফ্যাক্টে দেয়):
`scripts/web/vendor.lock.json` (প্রতিটি CDN ফাইলের SHA-256) ও `tools/quran-data/quran-data.lock.json` (কুরআন ডেটার SHA-256)।
এগুলো কমিট করলে পরবর্তী বিল্ডে কোনো ফাইল বদলালে ধরা পড়ে; **রিলিজ বিল্ড লক-ফাইল ছাড়া শুরুই হয় না** এবং অমিল হলে ব্যর্থ হয়।
(Google Fonts ফাইল ইচ্ছাকৃতভাবে "volatile": Google সময়ে সময়ে সিএসএস বদলায়, তাই শুধু সতর্কতা।)
কুরআন ডেটা নিয়ে যাচাই: ১১৪ সূরা, ৬২৩৬ আয়াত, প্রতি সূরার আয়াত-সংখ্যা, ক্রমিক নম্বর, জুজ/পৃষ্ঠা/রুকু/হিযব একমুখী ও ফাঁকহীন, প্রতিটি অনুবাদ আরবির সাথে আয়াত-ধরে সারিবদ্ধ, কোনো খালি টেক্সট নেই। টেক্সট **একটি বর্ণও বদলানো হয় না**; উৎস ভুল হলে বিল্ড ব্যর্থ হয়।

## ৩. Firebase / Google Cloud — যা এখনই দেখে নিতে হবে

অ্যাপের অরিজিন এখন `https://localhost` (Capacitor)। ওয়েবসাইটের অরিজিন নয়। তাই:

1. **Firebase Authentication → Settings → Authorized domains:** `localhost` আছে কি না দেখুন (ডিফল্টে থাকে)।
2. **Google Cloud Console → API key (Firebase Web key) → Application restrictions:** যদি "HTTP referrers" দিয়ে শুধু `quranbangla.vercel.app/*` অনুমোদিত থাকে, তাহলে অ্যাপে লগইন/Firestore **ব্যর্থ হবে**। `https://localhost/*` যোগ করুন (অথবা নিয়ন্ত্রণ ঢিলে করুন)। *এটা আমি যাচাই করতে পারিনি — আপনার প্রজেক্টের সেটিং আমার নাগালে নেই।*
3. **Google দিয়ে সাইন-ইন (popup)** WebView-তে আগেও কাজ করত না, এখনো না (পরিবর্তন নেই)। নেটিভ Google সাইন-ইন পরের ধাপে।
4. **ব্যাকএন্ড CORS:** `api/_cors.js` অ্যাপের অরিজিন (`https://localhost`, `http://localhost`, `capacitor://localhost`) অনুমোদন করে — কখনও `*` নয়, কুকি নয় (Firebase ID টোকেন)। আরও অরিজিন লাগলে `CORS_ALLOWED_ORIGINS`।
5. **Vercel deploy:** `.vercelignore`-এ `tools`, `build`, `scripts` যোগ হয়েছে (ওয়েবসাইটে এগুলো আর যাবে না)।

## ৪. নেটিভ মডিউল

### হোম-স্ক্রিন উইজেট (Kotlin, `RemoteViews`, Compose নয়)
| উইজেট | দেখায় | ট্যাপ করলে |
|---|---|---|
| পরবর্তী নামাজ | নাম, সময়, **লাইভ কাউন্টডাউন** (`Chronometer`, লঞ্চার চালায় — আমাদের কোনো wake-up নেই), বর্তমান ওয়াক্ত | `quranbangla://prayer` |
| আজকের আয়াত | আরবি + অনুবাদ + রেফারেন্স — **অ্যাপের হোম কার্ডের একই আয়াত** (একই ৩০টির পুল, একই দিন-নম্বর) | সেই আয়াত পাঠে |
| পড়া চালিয়ে যান | শেষ সূরা/আয়াত, কুরআনের কত % পড়া, বাটন | `quranbangla://continue` |
| কুরআন শর্টকাট | কুরআন · সার্চ · কিবলা · তাসবিহ | সংশ্লিষ্ট স্ক্রিন |
| পরিকল্পনা ও রিমাইন্ডার | পড়ার পরিকল্পনা (planner) অগ্রগতি, আজ সম্পন্ন কি না, স্ট্রিক, পরবর্তী রিমাইন্ডার | `quranbangla://planner` |

সব লাইট/ডার্ক (`values-night`), বাংলা/ইংরেজি, রিসাইজযোগ্য। আপডেট **ইভেন্ট-চালিত**: প্রতিটি নামাজের সময় ও মধ্যরাতে একটাই ইনএক্স্যাক্ট অ্যালার্ম + অ্যাপ ডেটা পাঠালে। কোনো লুপ/পোলিং নেই।

### রিমাইন্ডার ইঞ্জিন (`AlarmManager`)
ক্যাটালগ (১৫টি, সব ডিফল্টে বন্ধ): ৫ ওয়াক্ত, জুমা (শুক্রবার, যোহরের ৬০ মিনিট আগে), তাহাজ্জুদ (রাতের শেষ তৃতীয়াংশ), সকাল/সন্ধ্যার আযকার, দৈনিক তিলাওয়াত, আজকের আয়াত, পড়ার পরিকল্পনা, সেহরি/ইফতার/তারাবীহ (শুধু রমজানে — হিজরি মাস ৯ থেকে শনাক্ত)।
- অ্যালার্ট ধরন: শব্দসহ / শুধু ভাইব্রেশন / নীরব (Android 8+ এ চ্যানেল-ভিত্তিক: ৪ ক্যাটেগরি × ৩ ধরন)।
- **নির্ভুল অ্যালার্ম:** `SCHEDULE_EXACT_ALARM` (ইউজারের দেওয়া "Alarms & reminders" অনুমতি)। না দিলে `setAndAllowWhileIdle` — কয়েক মিনিট দেরিতে আসতে পারে, কিন্তু আসে। `USE_EXACT_ALARM` ইচ্ছাকৃতভাবে **ব্লক** (Google Play শুধু অ্যালার্ম/ক্যালেন্ডার অ্যাপকে দেয়)।
- রিবুট, অ্যাপ আপডেট, সময়/টাইমজোন পরিবর্তন, অনুমতি পরিবর্তনে সব আবার শিডিউল (`BootReceiver`)।
- অনুমতির অবস্থা ও সিস্টেম-সেটিংস বাটন (নোটিফিকেশন, নির্ভুল অ্যালার্ম, ব্যাটারি) **রিমাইন্ডার স্ক্রিনে** (Discover → রিমাইন্ডার; শুধু Android অ্যাপে দেখায়)।
- **সীমাবদ্ধতা:** কিছু কোম্পানির ফোনে (ব্যাটারি অপ্টিমাইজেশন) অ্যালার্ম আটকে যেতে পারে — সব ডিভাইসে নিখুঁত সময়ের প্রতিশ্রুতি দেওয়া হয়নি; স্ক্রিনে সতর্কতা ও সেটিংসের বাটন আছে।
- **আজান অডিও** নেই (কপিরাইট/সাইজ; পরে ডাউনলোড ম্যানেজার দিয়ে)। এখন ডিফল্ট নোটিফিকেশন সাউন্ড।

### Room ডাটাবেস (SQLite)
ভার্সন ১: `reading_history`, `bookmarks`, `notes`, `listening_history`, `downloads`, `learning_progress`, `key_value`; `exportSchema = true` (স্কিমা `android/app/schemas/` → `build-reports`)। `Migrations.kt` খালি (ভার্সন ১)। **ডিজাইন সিদ্ধান্ত:** অ্যালার্ম ও উইজেটের তথ্য (সেটিংস, রিমাইন্ডার তালিকা) `SharedPreferences`-এ — অ্যালার্ম/বুট রিসিভারে ডাটাবেস খুলে ব্যাকগ্রাউন্ড থ্রেডের অপেক্ষা না করে তাৎক্ষণিক পড়তে; বড়/সম্পর্কযুক্ত ডেটা Room-এ। এই ডাটাবেস এখনো ওয়েব অ্যাপের সাথে সিঙ্ক হয় না (টেবিল প্রস্তুত, ব্যবহার পরের ধাপে)।

### তাসবিহ (নতুন ফিচার)
অ্যাপে আগে **ছিলই না**। এখন: ৫টি জিকির + ফ্রি কাউন্টার, লক্ষ্য ৩৩/৯৯/১০০/∞, রাউন্ড, আজকের মোট, আনডু (৫০ ট্যাপ পর্যন্ত), রিসেট, হ্যাপটিক, ডিভাইসে সংরক্ষণ। Discover-এ, `quranbangla://tasbih`-এ এবং উইজেটের বোতামে।

## ৫. কোনটা যাচাই হয়েছে, কোনটা হয়নি (সততার তালিকা)

**সত্যিই চালিয়ে যাচাই হয়েছে** (এই স্যান্ডবক্সে, `docs/standalone/TESTING.md`):
Node টেস্ট ২৯০ (পাস), Python ২২, Android প্যাচার self-test ৩৮০ চেক, প্রিফ্লাইট ০/০, `tsc --strict` পরিষ্কার, নেটিভ-লিন্ট ০ এরর (+ ২৭ রকম ইচ্ছাকৃত ভুল ধরা প্রমাণিত)।

**যাচাই হয়নি — আপনার ফোন/CI-তে প্রথম রানেই জানা যাবে:**
- ❌ **Kotlin কম্পাইল।** এই পরিবেশে Kotlin কম্পাইলার/Gradle/Android SDK নেই, নেটওয়ার্কও নেই। ২,১১০ লাইন Kotlin লেখা হয়েছে সতর্কতার সাথে ও স্ট্যাটিক-লিন্টে (ইমপোর্ট, রিসোর্স, ম্যানিফেস্ট, Room কোয়েরি) যাচাই করে, কিন্তু **কম্পাইল হয়নি**। প্রথম CI রানে কম্পাইল-এরর আসতে পারে; তখন `full` ব্যর্থ হয়ে `safe` APK তৈরি হবে (ইনস্টলযোগ্য, নেটিভ মডিউল ছাড়া)। লগ পাঠালে ঠিক করে দেব।
- ❌ **APK/AAB তৈরি** — কোনো APK এই পরিবেশে বানানো হয়নি।
- ❌ **ফোনে এয়ারপ্লেন-মোড টেস্ট, উইজেট ইনস্টল/আপডেট, রিবুটের পর অ্যালার্ম, ব্যাটারি-নিষেধ, ব্যাকগ্রাউন্ড** — কিছুই ডিভাইসে চালানো হয়নি।
- ❌ **বাস্তব কুরআন ডেটা ডাউনলোড** — পাইপলাইন কৃত্রিম ফিক্সচারে পরীক্ষিত (টেস্ট-ফিক্সচারে প্রতিটি টেক্সটে "fixture" লেখা, কখনও শিপ হয় না)। আসল ডেটা প্রথম CI রানে `api.alquran.cloud` থেকে আসবে ও ওপরের সব যাচাই পেরোলে তবেই বান্ডলে ঢুকবে। উৎস-API-র গঠন (`/quran/{edition}`) আমার জানা অনুযায়ী লেখা — প্রথম রানে নিশ্চিত হবে।
- ❌ **CDN ডাউনলোড** (Firebase/Fonts/FA) — ফেইক CDN-এ পরীক্ষিত; আসল ডাউনলোড CI-তে।
- ⚠️ জুজ-শুরুর পরীক্ষা: `Juz ৪` সহ কয়েক জায়গায় মাসহাফভেদে ১ আয়াত পার্থক্য সম্ভব; আসল ডেটায় অমিল পেলে বিল্ড সতর্কতা দেয় (ব্যর্থ নয়)।
