## খ. যা চালানো **হয়নি** — আপনার ফোন/CI-তে

### ১. কম্পাইল ও বিল্ড (CI-তে)
- [ ] `Build Android app` ওয়ার্কফ্লো চালানো; `Build the web bundle` ধাপ সবুজ (লগের শেষ লাইন: ফাইল সংখ্যা, MB)।
- [ ] `full` APK কম্পাইল হয়েছে? (না হলে `safe` তৈরি হয়; কম্পাইল-লগ দিন)
- [ ] `audit-apk` রিপোর্টে **"Standalone web bundle: N files verified byte for byte"** ও "server.url: none"।
- [ ] `build-reports` আর্টিফ্যাক্ট থেকে `vendor.lock.json` ও `quran-data.lock.json` কমিট।
- [ ] রিলিজ: signed APK + AAB (`RELEASE.md`)।

### ৩. নেটিভ (ডিভাইসে) — §18
