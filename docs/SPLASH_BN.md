# লঞ্চ স্প্ল্যাশ (কোডে আঁকা) — Android অ্যাপ

অ্যাপ খোলার সময় যে অ্যানিমেটেড স্ক্রিনটা আসে, সেটা এখন **পুরোটাই কোডে আঁকা**: ইনলাইন SVG + CSS অ্যানিমেশন। কোনো `splash.json` নেই, Lottie বা অন্য অ্যানিমেশন লাইব্রেরি নেই, আলাদা কোনো ফাইল নামানোরও দরকার নেই — তাই দেরিতে আসার বা ইন্টারনেট না থাকলে ব্যর্থ হওয়ার কিছু নেই।

> ওয়েবসাইটে এর কিছুই লোড হয় না। শুধু Android অ্যাপে চলে (`js/platform.js` ওয়েবসাইটে এর আগেই থেমে যায়)।

## কী দেখা যায় (প্রায় ২ সেকেন্ড)

1. পর্দার রং হুবহু নেটিভ স্প্ল্যাশের রং (`#092723`, `manifest.json`-এর `theme_color`) — তাই নেটিভ থেকে হ্যান্ড-ওভারে **রঙের ঝলক নেই**।
2. পেছনে নরম পান্নাসবুজ আভা ধীরে ফুটে ওঠে; সরু সোনালি বলয় আর অষ্টভুজ তারা (ইসলামী জ্যামিতি) খুব ধীরে ঘোরে।
3. কুরআনের লোগো **সরু সোনালি রেখায় নিজে নিজে আঁকা হয়**, তারপর উষ্ণ সোনালি গ্রেডিয়েন্টে ভরাট হয়।
4. "Quran Bangla" ওয়ার্ডমার্ক অক্ষর অক্ষর করে বাঁ দিক থেকে উঠে আসে।
5. নিচে একটা সরু সোনালি আলো চলতে থাকে — অ্যাপ প্রস্তুত না হওয়া পর্যন্ত।
6. শেষে পুরো স্ক্রিন হালকা জুমসহ মিলিয়ে গিয়ে নিচে আগে থেকে আঁকা অ্যাপ-UI দেখায়।

"অ্যানিমেশন বন্ধ" (reduced motion) চালু থাকলে আঁকার অ্যানিমেশন হয় না: তৈরি লোগো দেখায়, একটা শান্ত ফেড, প্রায় ১.১ সেকেন্ড।

## কেন ঝলক বা ল্যাগ হয় না

- **ফাইল মাত্র একটা** (`app/js/splash.js`, লোগো ও ওয়ার্ডমার্কের ভেক্টরসহ) — আগে লাগত স্ক্রিপ্ট + Lottie রানটাইম + JSON, তিনটা।
- ওভারলে আগে তৈরি হয় **থামানো অবস্থায়** (সব অ্যানিমেশন paused, পর্দা শুধু নেটিভ রঙ)। প্রথম ফ্রেম আঁকা হলে তবেই নেটিভ স্প্ল্যাশ ছাড়া হয়; নেটিভ ফেড (≈২০০ মি.সে.) শেষ হলে অ্যানিমেশন শুরু হয় — তাই কোনো ফ্রেম নেটিভ স্প্ল্যাশের নিচে হারায় না।
- শুধু `transform`, `opacity` আর কয়েকটা ছোট পাথের রেখা অ্যানিমেট হয়। **blur, shadow, filter, mask, লেআউট-বদলানো কোনো প্রপার্টি নেই** — দুর্বল ফোনেও মসৃণ। (`tests/splash.test.js` এটা পাহারা দেয়।)
- ওভারলে সরে কেবল যখন **অ্যানিমেশন শেষ এবং অ্যাপ-UI প্রস্তুত** — যেটা পরে হয়।
- সিস্টেম বার (স্ট্যাটাস/নেভিগেশন) স্প্ল্যাশের সময় একই গাঢ় রঙে থাকে, শেষে অ্যাপের থিমের রঙে ফেরে।

## নিরাপত্তা-জাল (কিছুই আটকে থাকবে না)

| ঘটনা | ফল |
|---|---|
| `splash.js` লোড না হলে / ৫ সেকেন্ডে শুরু না হলে | স্প্ল্যাশ বাদ, নেটিভ স্প্ল্যাশ ছেড়ে অ্যাপ স্বাভাবিক চলে (পরে এসে পৌঁছালেও কিছু করে না) |
| স্প্ল্যাশ ১৪ সেকেন্ডের বেশি চললে | ওভারলে জোর করে সরানো হয় |
| তবুও কিছু ভুল হলে | `platform.js`-এর নিজস্ব ১৬ সেকেন্ডের শেষ-উপায় টাইমার ওভারলে সরায় |
| অ্যাপ-UI ১২ সেকেন্ডে চালু না হলে | আগের মতোই ওয়েবসাইট-UI-তে রিলোড (ফাঁকা স্ক্রিন কখনো নয়) |

অফলাইনে প্রথম লঞ্চ থেকেই চলে: সার্ভিস ওয়ার্কার সক্রিয় হওয়া মাত্র ফাইলটা ক্যাশ করা হয়।

## বদলাতে চাইলে — সবই `app/js/splash.js`-এ

| কী | কোথায় |
|---|---|
| সময় (মোট দৈর্ঘ্য, ফেড) | ফাইলের ওপরের `var T = { … minShow: 2000 … leave: 360 … }` |
| পর্দার রং | `var BG = '#092723'` — **`manifest.json`-এর `theme_color`-এর সাথে একই রাখতে হবে** (টেস্ট মিলিয়ে দেখে) |
| সোনালি রং / গ্রেডিয়েন্ট | `logoSvg()`-এর `stop-color`গুলো, আর CSS-এ `#F2D48A`, `#FFE9A8` |
| লোগোর আকার | CSS-এর `--m:min(46vw,208px,38vh)` |
| অ্যানিমেশনের ধাপ-সময় | CSS-এর `animation: … 950ms … calc(120ms + var(--i)*40ms)` (লোগোর রেখা), `940ms + var(--d)*340ms` (অক্ষর) |
| লোগো / ওয়ার্ডমার্ক বদলানো | `LOGO` (৯টা কনটুর) ও `WORD` (১১টা অক্ষর) অ্যারে — `M x y l dx dy … z` ফরম্যাটের বন্ধ পাথ |

সময় বা রং বদলালে **`js/data.js`-এর `SW_VERSION` একটা বাড়ান**, নইলে ইনস্টল করা অ্যাপ সার্ভিস ওয়ার্কারের পুরোনো ক্যাশ থেকে পুরোনো ফাইল দেখাতে পারে।

## পরীক্ষা

```bash
node --test tests/splash.test.js                  # ব্রাউজার ছাড়া: গঠন, আর্টওয়ার্ক, রং, সময়, ওয়েবসাইট আলাদা
PLAYWRIGHT_MODULE=/path/to/playwright node --test tests/ui/splash.ui.test.js
                                                  # আসল Chromium-এ: প্রথম ফ্রেম, ছবি (পিক্সেল), বার, ফলব্যাক, লেআউট, অফলাইন
node android-build/preflight.mjs                  # splash.js স্বয়ংসম্পূর্ণ কি না (নেটওয়ার্ক/JSON/URL নেই)
```

যা এখানে পরীক্ষা করা যায় না: **আসল ফোনে** নেটিভ সিস্টেম-স্প্ল্যাশ থেকে হ্যান্ড-ওভার কেমন দেখায়। APK ইনস্টল করে একবার চোখে দেখে নেওয়া ভালো।
